# --- The model. Every score in this project comes from lgb.LGBMRegressor. ---
#
# PINNED EXACTLY, AND NOT AS A STYLE CHOICE. The published headline is the
# output of one specific version's arithmetic. A one-bit float difference is
# enough to flip a LightGBM split, reorder near-tied names at the TOP_N=8
# boundary and move CAGR by two thirds of a point -- measured, see
# KNOWN_ISSUES.md, "The headline is not reproducible from the artefacts on disk
# to better than about a point". A minor-version bump is free to change split
# arithmetic, so a floor here would not preserve the numbers.
lightgbm==4.6.0

# scikit-learn is NOT optional here even though nothing imports it directly.
# lgb.LGBMRegressor is defined in lightgbm.sklearn, and lightgbm declares
# scikit-learn only as an EXTRA ("scikit-learn>=0.24.2; extra == 'scikit-learn'"),
# so installing lightgbm alone does not bring it in.
scikit-learn>=1.5,<2.0

# --- Core data handling ---
pandas>=2.2,<3.0
numpy>=1.26,<2.3

# pyarrow is NOT optional here even though nothing imports it directly.
# STEP 16 nautilus/nt_export_scores.py calls df.to_parquet / pd.read_parquet,
# and pandas needs a parquet engine for both.
pyarrow>=14.0

# scipy is imported directly by STEP 4 diagnose_decay.py and STEP 6
# reality_check.py. It is also a hard dependency of lightgbm, but it is listed
# on its own account so that dropping lightgbm would not silently break STEP 6.
scipy>=1.10

# --- Backtesting / execution engine ---
# Imported by qbeast_in_charges.py, which the pipeline reaches for cost
# modelling. Sets the 3.12 Python floor noted in the header.
nautilus_trader>=1.220,<1.230

# --- Plotting / equity curve charts ---
matplotlib>=3.8,<3.12

# --- Parallel seed fitting (engine_core.score_monthly, one process per seed) ---
joblib>=1.3
