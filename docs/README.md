**THE COMBINED CHART'S FILENAME NAMES ITS SELECTION, AND THE PAIR CHART IS ALWAYS
REFRESHED.** `make_combined_universes.py` draws one comparison across whichever
universes the run selected and derives the filename from exactly those, tags in
`universes/registry.REPORT_ORDER`: `--universe all` writes a chart naming all
eight.

**Whenever both nifty100 and midcap150 are selected it also writes
`chart_COMBINED_nifty100_midcap150.png`**, the standing comparison of the two
certified universes (`registry.CERTIFIED`), so `--universe all` and
`--universe nifty100,midcap150` both keep it current. It is not copied here.

A single selected universe writes no combined chart at all.

**These do not update themselves.** If the numbers move — a data fix, a parameter
change, a re-run on a different window — the copies here go stale silently while
the README still displays them. Re-copy both after any run that changes the
headline figures, or delete them and drop the images from the README.
