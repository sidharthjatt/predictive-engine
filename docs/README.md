# docs/

Published copies of pipeline output, kept here so the top-level README can embed
them. Everything under `results*/metrics/` is generated and untracked; these are
copies, and the originals stay where the pipeline writes them.

| file | generated by | original |
|---|---|---|
| `chart_COMBINED_n100_mid.png` | `results/make_combined_n100_mid.py` (run_all.py STEP 10i) | `results_n100/metrics/chart_COMBINED_n100_mid.png` |
| `chart_decay.png` | `results/diagnose_decay.py` (run_all.py STEP 4) | `results/metrics/chart_decay.png` |

**These do not update themselves.** If the numbers move — a data fix, a parameter
change, a re-run on a different window — the copies here go stale silently while
the README still displays them. Re-copy both after any run that changes the
headline figures, or delete them and drop the images from the README.
