copies, and the originals stay where the pipeline writes them.

**THE COMBINED CHART'S FILENAME NAMES ITS SELECTION, AND THE PAIR CHART IS ALWAYS
REFRESHED.** `make_combined_universes.py` draws one comparison across whichever
universes the run selected and derives the filename from exactly those, so
`--universe all` now writes `chart_COMBINED_n100_mid.png`, because the registry is
exactly that pair since the 58 and the 74 were deleted.

**In addition, whenever both n100 and mid are selected it also refreshes
`chart_COMBINED_n100_mid.png`** -- the file copied here. n100-vs-mid is a standing
published comparison, not a by-product of the selection happening to be those two,
so `--universe all` and `--universe n100,mid` both keep it current. The copy in
this directory therefore does not go stale after a full run.

A single selected universe writes no combined chart at all.

**These do not update themselves.** If the numbers move — a data fix, a parameter
change, a re-run on a different window — the copies here go stale silently while
the README still displays them. Re-copy both after any run that changes the
headline figures, or delete them and drop the images from the README.
