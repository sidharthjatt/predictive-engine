STILL WRONG -- one root cause, three symptoms
  From 2017-03-31 (row 28) onward the `symbols` column stops being a snapshot and
  becomes a running total. Up to 2016-11-15 it holds 98-114 names, which is right
  for a 100-name index. Then: 227 at 2017-03-31, 323 at 2017-09-29, 461 at
  2018-04-02, 585 at 2019-03-29, peaking at 854 at 2022-03-31. Across the file it
  adds 783 names and removes only 41.

  1. Cumulative membership: 15 separate reconstitutions grow the list, essentially
     nothing is ever removed.
  2. 45 of 114 exclusion entries name a symbol that the SAME row also lists as an
     inclusion -- e.g. CASTROLIND, BHARATFORG and APOLLOHOSP on 2017-03-31. A
     reconstitution adds a name or drops it, not both on one date.
  3. 13 of 49 transitions fail list[t] = list[t-1] + inclusions - exclusions, the
     first being 2017-03-31 -- the same date the growth starts.

  index_type is uniformly "Nifty100" on all 50 rows, so this is NOT two indices
  interleaved in one file. Rows 42-49 (2022-08-08 onward) do shrink by 1-3 names
  each and have zero unremoved exclusions, so the removal logic works there; it is
  the 2017-03-31 to 2022-03-31 band that never applies it.

MINIMAL CHANGE NEEDED
  Rebuild `symbols` as a running state rather than a running total:
      symbols[t] = symbols[t-1] + inclusions[t] - exclusions[t]
  applying the subtraction, and emit each name in either inclusions or exclusions
  on a given date but not both. Nothing else in the file needs to change: the
  dates, the anchors, and the post-2022 rows are already correct. The validator
  passes when every row satisfies that identity and each list stays near 100 names.

  Verify with:  python3 results/survivorship.py validate <file> --index nifty100
  Exit 0 = pass, 2 = fail.

SEPARATE LIMITATION, NOT A DEFECT IN THE FILE
  784 of the 870 distinct names have no price file in this repo. Even a corrected
  membership history would leave residual survivorship bias until those are
  sourced, and that has to be reported with any result computed from it.
