NOTE ADDED 2026-08-13 -- ALL VERDICTS BELOW PREDATE THE FEATURE-DENSITY FIX
================================================================================
Every experiment recorded here was run on a panel produced BEFORE the
beta_60 / idio_vol_60 density fix of 2026-08-13. That bug computed both features
with rolling(60) over the union date index, so a symbol that did not trade on a
union date lost its next 60 windows and those rows were dropped from training.

The baseline these verdicts sit against has moved:

    58 universe : CAGR 16.45% -> 13.16%   Sharpe 1.36 -> 1.11
    74 universe : CAGR 14.65% -> 15.22%   Sharpe 1.27 -> 1.35

THE VERDICTS ARE NOT WITHDRAWN. Both arms of every experiment used the same
panel, so each comparison remains internally valid; what changed is the baseline
they are measured against, not the contrast between arms.

THE EXPERIMENTS ARE DELIBERATELY NOT RE-RUN. Re-testing seventeen hypotheses on a
new panel to see whether any now passes is exactly the multiple-testing failure
that pre-registration exists to prevent. Any re-test would need its own
pre-registration, written before the numbers are seen, and would have to carry
the full trial count.

  Q1 "Does MORE data help?"  -> rolling vs expanding
     58 Sharpe:  expanding 1.54 | 3y 1.32 | 2y 0.97 | 1y 1.13
     74 Sharpe:  expanding 1.45 | 3y 1.30 | 2y 1.11 | 1y 1.26
     -> YES, more data is better. Expanding wins both universes.

  Q2 "Does FADING old data help?" -> sample_weight = lambda^(age months)
     58 Sharpe:  uniform 1.54 | L.95 1.34 | L.98 1.48 | L.995 1.56
     74 Sharpe:  uniform 1.45 | L.95 1.09 | L.98 1.40 | L.995 1.44
     -> NO. Monotonic: more fade = worse. Uniform wins.
     LITMUS PASSED: lambda .995 (N_eff 33 years >> 8-year dataset) reproduced
     uniform almost exactly, confirming the test itself was sound.

  Conclusion: old data (2016-18) is still relevant. Retraining scheme is not
  the lever. Question closed.
